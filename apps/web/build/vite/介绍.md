## 已完成的分层结构

```text
apps/web/vite.config.ts
apps/web/build/vite/common.ts
apps/web/build/vite/development.ts
apps/web/build/vite/production.ts
apps/web/build/vite/TODO.md
```

对应职责：

### `common.ts`

所有环境通用：

- 插件基础配置
- alias
- 依赖预构建
- CSS
- 静态资源
- Worker
- Rollup 输出
- 基础 Build 配置
- Server 和 Preview 基础配置

### `development.ts`

开发环境：

- Source Map
- 关闭压缩
- 关闭 CSS 压缩
- 开发日志
- 不生成生产 Manifest

### `production.ts`

生产环境：

- Legacy
- esbuild 压缩
- CSS 压缩
- 关闭 Source Map
- Bundle 分析
- 生产日志
