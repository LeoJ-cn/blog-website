# 一种基于物联网与人工智能的智能盆栽养护系统

**技术领域**

本发明涉及植物养护设备技术领域，具体涉及一种基于物联网与人工智能的智能盆栽养护系统，适用于家庭、办公场所及商业空间的室内植物智能化管理。

**背景技术**

随着城市化进程的不断加快和人们生活水平的持续提高，越来越多的家庭和办公场所选择在室内种植盆栽植物，以美化环境、净化空气、缓解压力。然而，现代生活节奏快、工作压力大，人们常常因出差、加班、旅游等原因无法及时照料盆栽，导致植物因缺水、缺光、温度不适或养分不足而枯萎死亡。据相关调查显示，城市家庭盆栽的年平均死亡率高达百分之四十以上，其中因养护不当造成的死亡占比超过七成。

传统的盆栽养护方式完全依赖人工经验，浇水施肥缺乏科学依据，难以满足不同种类植物的个性化需求。不同植物对水分、光照、温度和湿度的要求差异显著，例如多肉植物喜干燥少水，而蕨类植物则需要高湿环境。普通用户往往难以准确掌握这些参数，导致养护效果不佳。此外，现有的一些自动浇水装置功能单一，仅能实现定时浇水，无法根据环境变化和植物实际状态进行动态调节，也无法实现远程监控和管理。

因此，亟需一种能够自动监测、智能分析并精准调节植物生长环境的智能养护系统，以解决上述技术问题。

**发明内容**

本发明的目的在于提供一种基于物联网与人工智能的智能盆栽养护系统，以解决现有技术中盆栽养护依赖人工经验、功能单一、无法远程管理且缺乏个性化调节能力的问题。

为实现上述目的，本发明采用如下技术方案：

一种基于物联网与人工智能的智能盆栽养护系统，包括花盆本体、控制模块、传感器模块、执行模块、无线通信模块、云端服务器和移动终端应用模块。

所述传感器模块设置于花盆本体内部及周围，包括土壤湿度传感器、土壤酸碱度传感器、光照强度传感器、环境温度传感器、空气湿度传感器和摄像头模块。土壤湿度传感器采用电容式非接触测量方式，精度高且耐腐蚀；光照强度传感器用于实时监测植物接受的光照量；摄像头模块用于定期拍摄植物图像，供人工智能模块进行生长状态分析。

所述控制模块分别与传感器模块和执行模块电连接，采用低功耗微处理器，用于接收传感器数据、运行控制算法并发出控制指令。控制模块内置植物种类数据库，存储有常见室内植物的最佳生长参数范围。

所述执行模块包括微型水泵、LED补光灯、加热片、微型风扇和雾化喷头。微型水泵通过硅胶管连接储水瓶，实现精准浇水；LED补光灯可根据植物需求提供特定光谱的补充光照；加热片和微型风扇配合实现温度调节；雾化喷头用于增加空气湿度。

所述无线通信模块与控制模块相连，采用Wi-Fi、蓝牙或ZigBee通信协议，用于将采集的环境数据和植物图像上传至云端服务器，并接收用户通过移动终端发送的远程控制指令。

所述云端服务器部署有人工智能分析模块，采用深度学习算法对植物图像进行识别与分析，判断植物是否存在叶片发黄、病虫害、徒长等异常状况，并结合环境数据生成养护建议。用户可通过移动终端APP随时查看植物状态、接收异常预警并进行手动干预。

**有益效果**

本发明通过多传感器融合技术实现对盆栽生长环境的全面监测，结合物联网通信和人工智能分析实现远程管理与智能决策。系统可根据植物种类自动匹配最佳养护方案，并依据实时数据动态调节浇水、光照、温度和湿度，有效提高盆栽成活率，降低养护难度。同时，摄像头模块与人工智能算法的结合实现了植物健康状态的视觉监测，能够及时发现病虫害等问题并发出预警。本发明具有智能化程度高、功能全面、操作便捷、实用性强的优点，可广泛应用于家庭、办公及商业场所的植物养护管理。

**具体实施方式**

实施例中，土壤湿度传感器采用电容式传感器，精度可达正负百分之三。微型水泵流量为每分钟五十毫升，每次浇水时间由控制模块根据湿度数据和植物种类自动计算。无线通信模块采用ESP32芯片，支持Wi-Fi和蓝牙双模通信。云端服务器采用MQTT协议接收数据，人工智能模块基于卷积神经网络实现植物图像分类与异常检测。用户通过手机APP可设置植物种类、查看历史数据和接收养护提醒。
