## 二、每章内容压缩规则

| 内容       | 新要求                 |
| -------- | ------------------- |
| 知识点      | 全部覆盖，使用表格或短段落       |
| 原理       | 先结论，再解释执行链路         |
| 核心 API   | 用法、关键参数、常见坑         |
| 核心代码     | 只展示最关键的 10～30 行     |
| 企业场景     | 问题 → 方案 → 效果        |
| Codex 实战 | 完整可复制 Prompt，不缩水    |
| 面试题      | 每题立即给标准答案，控制在 3～5 句 |
| 面试追问     | 直接给答案，不重复基础解释       |
| 章节总结     | 约 7 行，3 列表格         |

特别注意： 每章的完整运行代码由 Codex 在 `blog-website` 仓库生成，我负责讲解核心代码及技术原理，避免在聊天中重复粘贴大量完整项目代码。
