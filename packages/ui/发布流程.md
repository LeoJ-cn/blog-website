针对当前项目，完整流程是：**检查源码 → 构建打包 → 验证安装包 → 登录 npm → 发布 → 核对结果**。

### 1. 检查本次发布内容

在仓库根目录执行：

```sh
cd /Users/leojm5/Documents/company/blog-website
git status --short
git diff
```

确认没有遗留的热更新验证文字，准备发布的代码已经保存。建议先提交发布相关改动，便于追踪 `0.1.0` 对应的源码。

当前包应满足：

- `name`：`@white55/ui`
- `version`：`0.1.0`
- 没有 `private: true`
- `license`：`MIT`
- 默认导出指向 `dist`
- Web、Storybook 的依赖为 `workspace:0.1.0`

### 2. 检查类型并构建

```sh
pnpm --filter @white55/ui typecheck
pnpm --filter @white55/ui build:vite
```

预期两个命令都成功，生成：

```text
packages/ui/dist/
├── index.js
├── button.js
├── ...
├── ui.css
├── styles/
└── types/
```

这里直接使用包内命令；当前根目录没有 `build:ui:vite` 命令。

### 3. 检查并生成安装包

```sh
cd packages/ui

npm pack --dry-run --ignore-scripts
pnpm pack --pack-destination /tmp
```

第二条命令会触发 `prepack`，再次检查类型和构建，生成：

```text
/tmp/white55-ui-0.1.0.tgz
```

检查压缩包：

```sh
tar -tzf /tmp/white55-ui-0.1.0.tgz
```

预期包含 `package.json`、`README.md`、`LICENSE` 和 `dist`；不应包含 `.figma`、`node_modules` 等文件。

### 4. 在独立项目验证安装包

使用一个仓库之外的 Vue 3 + Vite 项目，手动安装：

```sh
pnpm add --save-exact /tmp/white55-ui-0.1.0.tgz vue@3.5.13 element-plus@2.9.5 @element-plus/icons-vue@2.3.2
```

在页面中使用：

```vue
<script setup lang="ts">
import { UiButton } from '@white55/ui/button'

import 'element-plus/dist/index.css'
import '@white55/ui/tokens.css'
import '@white55/ui/theme.css'
import '@white55/ui/ui.css'
import '@white55/ui/button.css'
</script>

<template>
  <UiButton type="primary">发布验证</UiButton>
</template>
```

手动启动该项目并构建，确认：

- 编辑器能识别组件属性和类型。
- 按钮显示、交互和样式正常。
- 项目生产构建成功。
- 消费项目**没有启用 `source-code`**。

这一步验证的才是用户实际安装到的发布产物。

### 5. 登录并确认版本

```sh
npm login --registry https://registry.npmjs.org/
npm whoami --registry https://registry.npmjs.org/
npm view @white55/ui versions --json --registry https://registry.npmjs.org/
```

账号必须拥有 `@white55` scope 的发布权限：

- 如果 `white55` 是个人用户名，使用该账号发布。
- 如果是组织，需要组织中的包发布权限。

如果查询返回 `E404`，可能是包尚不存在；仍需确认 scope 权限。如果已经存在 `0.1.0`，需要换新版本，不能覆盖。

### 6. 发布已验证的压缩包

推荐直接发布第 4 步验证过的同一个文件：

```sh
npm publish /tmp/white55-ui-0.1.0.tgz \
  --access public \
  --registry https://registry.npmjs.org/
```

按终端提示完成身份验证。公开 scoped 包使用 `--access public`，具体认证要求见 [npm 官方发布说明](https://docs.npmjs.com/creating-and-publishing-scoped-public-packages/)。

### 7. 核对发布结果

```sh
npm view @white55/ui@0.1.0 version --registry https://registry.npmjs.org/
npm view @white55/ui dist-tags --json --registry https://registry.npmjs.org/
```

预期版本为 `0.1.0`，`latest` 指向 `0.1.0`。也可以查看 [npm 包页面](https://www.npmjs.com/package/@white55/ui)。

最后，在独立消费项目中改为安装注册表版本：

```sh
pnpm add --save-exact @white55/ui@0.1.0
```

重新验证类型、页面和构建。发布确认后，可给对应提交添加 `ui-v0.1.0` Git tag。
